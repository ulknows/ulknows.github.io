Feature
General Node - Write anything if you want.
Static Node - Allow to create the variable to input to the Formula Node.
Formula Node - Is operation to calculate the result (Allow to input from the Static Node)
Variable - Store the data from Formula, Static or standalone value and It have a get, set methods.
